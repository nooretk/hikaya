# Backend Module

## Purpose

The backend will provide APIs for managing locations, stories, users, media, AI requests, and user contributions.

## Planned APIs

- GET /locations
- GET /locations/{id}
- GET /stories/{location_id}
- POST /contributions
- POST /ai/generate-story
- POST /ai/ask-guide

## Current Status

The backend is currently in the planning phase. API structure and database schema will be finalized before implementation.
